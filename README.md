## Por qué main muestra pocos archivos

Esta rama conserva la plantilla y la especificación original. La aplicación completa se encuentra en feature/gestor-incidencias, pendiente de revisión real del compañero e integración mediante el PR #1. Los enlaces anteriores llevan directamente a la versión completa y sus documentos. No se ha sustituido una revisión del compañero con una aprobación ficticia.

## Estado al 25 de octubre de 2026

La aplicación WinForms .NET Framework 4.7.2 compila en Release y pasan ocho grupos de aserciones. Se verificaron registro, edición, transiciones, filtros y persistencia tras reiniciar. Dos ejecuciones de Actions para d007240 terminaron correctamente.

La entrega académica aún requiere revisión del compañero, edición final del informe y presentación, y completar la organización remota de Issues, Project y milestone. La matriz distingue lo realizado de las propuestas. El usuario editará el diseño de los documentos.
