## ¿Qué problema resuelve Git en el desarrollo real?
Conserva un historial recuperable y permite colaborar en ramas. En este caso permite ubicar el cambio que agregó una regla o introdujo un defecto sin depender de carpetas duplicadas.

## ¿Por qué DevOps es importante en la actualidad?
Permite repetir compilación y comprobaciones de manera consistente antes de integrar o distribuir. El workflow conserva evidencia, pero su resultado depende de que las pruebas cubran necesidades útiles.

## ¿Cómo la IA está cambiando la programación?
Genera código a partir de instrucciones y contexto. El esfuerzo humano se concentra también en definir criterios, revisar decisiones y probar errores. Los integrantes siguen siendo responsables de comprender la aplicación.

## ¿Qué herramienta fue más útil y por qué?
Para construir este caso, GitHub Copilot en Visual Studio fue especialmente útil porque generó entidades, controlador, persistencia y formularios a partir de las especificaciones dentro del mismo entorno. Git y Actions permitieron conservar y comprobar esos cambios. El dúo debe confirmar que esta valoración refleja su experiencia y justificarla con un ejemplo del chat real.
